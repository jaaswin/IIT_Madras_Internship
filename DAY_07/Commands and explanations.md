# DNS Server Installation, Configuration and Testing

## 1. Introduction

This report contains the Linux commands used during the **DNS Server Installation, Configuration and Testing** task. Each command is listed with its definition and purpose in the task.

---

## 2. Network Commands

### 2.1 `ip addr`

**Definition:**
Displays the IP addresses and network interfaces configured on the Linux system.

**Purpose:**
Used to identify the active network interface and check the assigned IP address.

---

### 2.2 `ip route`

**Definition:**
Displays the routing table of the Linux system.

**Purpose:**
Used to check the default gateway and available network routes.

---

## 3. DNS Server Installation Commands

### 3.1 `sudo apt update`

**Definition:**
Updates the local package database with information about the latest available software packages.

**Purpose:**
Used before installing the DNS server package.

---

### 3.2 `sudo apt install bind9`

**Definition:**
Installs the **BIND9 DNS server** on Ubuntu/Linux.

**Purpose:**
Used to install the DNS server software required for the task.

---

### 3.3 `sudo apt install dnsutils`

**Definition:**
Installs DNS testing utilities such as `nslookup` and `dig`.

**Purpose:**
Used to test and troubleshoot DNS name resolution.

---

## 4. DNS Service Commands

### 4.1 `sudo systemctl status bind9`

**Definition:**
Displays the current status of the BIND9 DNS service.

**Purpose:**
Used to verify whether the DNS server is running correctly.

---

### 4.2 `sudo systemctl start bind9`

**Definition:**
Starts the BIND9 DNS service.

**Purpose:**
Used to start the DNS server if it is not running.

---

### 4.3 `sudo systemctl restart bind9`

**Definition:**
Stops and starts the BIND9 service again.

**Purpose:**
Used after changing the DNS configuration so that the new configuration is loaded.

---

### 4.4 `sudo systemctl enable bind9`

**Definition:**
Configures BIND9 to start automatically when the Linux system boots.

**Purpose:**
Used to make the DNS service start automatically after system restart.

---

## 5. DNS Configuration Commands

### 5.1 `sudo nano /etc/bind/named.conf.options`

**Definition:**
Opens the BIND9 options configuration file using the Nano text editor.

**Purpose:**
Used to configure DNS server options such as DNS forwarders and query settings.

---

### 5.2 `sudo nano /etc/bind/named.conf.local`

**Definition:**
Opens the local BIND9 configuration file.

**Purpose:**
Used when configuring custom DNS zones such as forward and reverse lookup zones.

---

### 5.3 `sudo named-checkconf`

**Definition:**
Checks BIND9 configuration files for syntax errors.

**Purpose:**
Used to verify that the DNS configuration is valid before restarting the service.

---

## 6. DNS Testing Commands

### 6.1 `nslookup www.example.com`

**Definition:**
Performs a DNS lookup for the specified domain name.

**Purpose:**
Used to verify that the DNS server can resolve a domain name into an IP address.

---

### 6.2 `dig www.example.com`

**Definition:**
Performs a detailed DNS query and displays DNS response information.

**Purpose:**
Used for detailed DNS testing and troubleshooting.

---

### 6.3 `resolvectl status`

**Definition:**
Displays the DNS resolver configuration of the Linux system.

**Purpose:**
Used to check which DNS servers are being used by the system.

---

### 6.4 `cat /etc/resolv.conf`

**Definition:**
Displays the contents of the DNS resolver configuration file.

**Purpose:**
Used to check the configured DNS nameserver information.

---

## 7. Network Connectivity Testing

### 7.1 `ping 8.8.8.8`

**Definition:**
Sends ICMP packets to the specified IP address to test network connectivity.

**Purpose:**
Used to verify basic IP connectivity without depending on DNS name resolution.

---

### 7.2 `ping www.example.com`

**Definition:**
Tests connectivity to a destination using its domain name.

**Purpose:**
Used to verify both DNS name resolution and network connectivity.

Example:

```text
Pinging www.example.com [IP_ADDRESS] with 32 bytes of data:
Reply from IP_ADDRESS: bytes=32 time=...
```

The exact IP address and response time can vary.

---

## 8. DNS Log and Troubleshooting Commands

### 8.1 `sudo journalctl -u bind9`

**Definition:**
Displays logs generated by the BIND9 service.

**Purpose:**
Used to monitor DNS service activity and identify errors.

---

### 8.2 `sudo journalctl -u bind9 -n 50`

**Definition:**
Displays the latest 50 log entries generated by BIND9.

**Purpose:**
Used to quickly check recent DNS service activity and errors.

---

### 8.3 `sudo ss -luntp | grep :53`

**Definition:**
Displays services listening on network ports and filters the output for DNS port 53.

**Purpose:**
Used to verify whether the DNS server is listening on port 53.

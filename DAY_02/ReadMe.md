# Day 2 – Internship Observation: Network Troubleshooting

On the second day of my internship, I observed the **Network Team** and learned how they monitor, analyze, and troubleshoot network-related issues in the organization.

### Key Observations

* Observed the network team working on **troubleshooting high CPU utilization** in network devices.
* The team investigated the possible reasons for **increased CPU usage** and analyzed the device's performance.
* I was introduced to **SISF (Switch Integrated Security Feature)** related CPU utilization and observed that SISF was consuming a significant portion of CPU resources, approximately **70%** in the case discussed.
* I also learned about **ND (Neighbor Discovery)** and its role in IPv6 networking.
* The team analyzed CPU utilization trends to identify **which devices had experienced higher CPU usage during the previous month**.
* Based on the analysis, the team discussed possible approaches to reduce unnecessary CPU processing and considered the impact of **IPv4/IPv6-related network traffic and protocols**.
* I observed how network engineers use monitoring data and historical trends before making troubleshooting decisions rather than making changes immediately.

### Network Monitoring and Management Tools Observed

During the observation, I was introduced to several tools used by the network team:

* **Nagios** – Network and system monitoring
* **Cisco tools** – Monitoring and managing Cisco network devices
* **MRTG (Multi Router Traffic Grapher)** – Monitoring network traffic and bandwidth utilization
* **Cacti** – Network monitoring and graphing of performance data

### Learning

I gained an understanding of how a professional network team works in a real-world environment, particularly how they:

**Monitor → Identify the problem → Analyze data → Find the root cause → Evaluate solutions → Take appropriate action**

I also understood the importance of learning **CCNA concepts** to build a strong foundation in networking, including routing, switching, IPv4, IPv6, network protocols, troubleshooting, and network monitoring.

Overall, Day 2 helped me understand that network administration involves continuous **monitoring, troubleshooting, performance analysis, and preventive maintenance** to maintain reliable network services.
